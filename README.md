# 健身搭子

双端（iOS / Android）健身 App：今天练什么、AI 分部位训练计划、饮食计算、训练日历、拍照手帐。基于 **Expo (React Native + TypeScript)**，一套代码同时支持两个平台，并支持浏览器 Web 预览。

## 视觉风格

「训练手帐」贴纸风：暖奶油纸底 + 白纸卡片硬偏移阴影 + 印章红主色 + 荧光黄马克笔高亮 + 虚线分隔。数字使用 Nunito，手写点缀使用 Caveat。全量动效基于 Reanimated（按压缩放、进度环/条动画、数字滚动、进场编排、训练完成撒花），交互配合 expo-haptics 触感反馈。

## 功能

| 模块 | 说明 |
|---|---|
| 🏠 今日 | 先制定计划（今日一键 / 本周一次排好，自动按分化排部位、跳过休息日）；没有计划时提示制定，有计划则打开直接显示当天课表与动作明细，可一键「换一套」；周计划打卡、连续达标统计 |
| 📋 计划 | 按部位（胸/背/肩/臂/腿/臀/核心）+ 侧重细分（如上胸、后束）+ 时长生成训练计划；未配置 AI 时用内置规则引擎，配置后由大模型从 114 个动作的本地动作库中编排（杜绝编造动作） |
| 🍚 饮食 | Mifflin-St Jeor 基础代谢 + 活动系数算每日热量与三大营养素；66 种常见食物库 + 手动录入，按餐记录、热量环与宏量进度条；**拍照识餐**：拍一张食物照片，AI（OpenAI 兼容视觉模型，如 glm-4v-flash）自动认食物、估重量、算热量，一键入账或贴进手帐 |
| 📖 手帐 | 按日期回看记录：月历上标出「完成训练（红底）/ 有手帐（粉点）」的日期，点任意日期显示**当天的训练（记录明细或计划）与手帐**，以及当天饮食摄入与体重（可补记）；本月训练次数/总组数/总容量统计。拍照 plog：训练完成自动生成总结页（撒花 + 数据 + 新纪录检测），一键进入手帐编辑器——照片贴成白边贴纸（可拖拽/旋转/缩放）、马克笔涂鸦、自动盖章训练数据；**只有当天可新增/编辑/删除，过去的页面只读** |
| 👤 我的 | 资料管理、营养目标、AI 服务配置、数据清空 |

训练执行页支持逐组记录重量×次数、组间休息计时（自动开始、结束震动提醒）、上次重量自动参考、训练容量统计。

## 快速开始

```bash
npm install
npx expo start
```

手机装 **Expo Go**（App Store / 应用商店搜索），扫码即可真机预览。iOS 也可用模拟器（`i` 键），Android 用模拟器按 `a` 键。

> 建议 Node.js ≥ 20.19.4（当前 SDK 的推荐版本）。

## AI 配置

App **默认已接入 DeepSeek**（`deepseek-flash`，支持文本与视觉）：AI 计划生成、拍照识餐开箱即用，无需任何配置。请求从手机直连 DeepSeek 官方接口。

要换成其他服务，在「我的 → AI 能力」点预设或手动修改，任意**兼容 OpenAI 接口**的服务均可：

| 服务 | 接口地址 | 模型示例 |
|---|---|---|
| DeepSeek | `https://api.deepseek.com` | `deepseek-flash` |
| 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-flash` |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |

关闭 AI 后使用内置规则引擎，完全离线可用。AI 生成的计划会校验动作 ID 必须来自本地动作库，解析失败自动回退规则引擎。

## 打包发布

```bash
npm i -g eas-cli
eas login

eas submit                      # 提交商店
```

上架国内安卓商店需要软著与逐店审核；App Store 需要开发者账号（$99/年）。

## 项目结构

```
app/                    页面（expo-router 文件式路由）
  _layout.tsx           根布局：字体加载 + 手势根 + 路由转场
  onboarding.tsx        6 步资料问卷（可重复进入编辑）
  session.tsx           训练执行（组记录/计时器）
  summary.tsx           训练总结（撒花/新纪录/拍手帐入口）
  plog.tsx              手帖编辑器（贴纸照片/涂鸦/盖章）
  (tabs)/               5 个主 Tab：今日/计划/饮食/手帐/我的
src/
  data/exercises.ts     动作库（114 个，含肌群/器械/难度/要领）
  data/foods.ts         食物库（66 种，每 100g 营养近似值）
  lib/planner.ts        分化模板 + 动作选取算法 + AI 编排
  lib/nutrition.ts      BMR/TDEE/宏量计算 + 减脂计划生成
  lib/ai.ts             OpenAI 兼容接口客户端
  store/                zustand + AsyncStorage 本地持久化
  components/           UI 组件库（手帖风设计系统）+ 体重曲线图
  theme.ts              设计 tokens：纸面色/印章红/荧光黄/阴影/字体
```

## 注意

- 训练与饮食建议仅供健康人群参考，不构成医疗建议
- 食物营养数据为近似值，动作库暂无演示动图（后续可接入）
- 手帐照片以 base64 存本地（AsyncStorage），换机或清数据会丢失；后续可接 Supabase Storage 云同步（方案见 [PLAN.md](PLAN.md)）
- Web 预览不支持「拍照」（用「从相册选」代替）；触感反馈仅在真机生效
- 数据全部存本地；如需云同步，后端方案见 [PLAN.md](PLAN.md)
